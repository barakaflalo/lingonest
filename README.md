## איך זה עובד

- **טעינה לפי צורך.** בפתיחה נטענים רק הליבה, שפת הממשק ושפת הלימוד. שאר השפות נטענות ברקע אחרי שנייה, כדי שאחוזי ההתקדמות יוצגו ושהכול יעבוד גם אופליין.
- **גרסה על כל קובץ.** כל קובץ נטען עם `?v=גרסה`, ובתוכו מוטבע אותו מספר גרסה. אם הטלפון מחזיק קובץ ישן מהמטמון, מופיע פס **"העדכון לא נטען במלואו — לחץ לרענון"**, במקום כפתורים שלא עובדים. אם `app.js` בכלל לא נטען, רשת הביטחון ב-`index.html` מציגה את אותו פס אחרי 6 שניות.
- **ההתקדמות נשמרת לפי מזהה קבוע.** מילים נשמרות כ-`W:<id>`, אותיות כ-`L:<מספר>`, תנועות כ-`V:<מספר>` ומילים שלי כ-`C:<id>`. **אסור לשנות מזהה קיים** — זה מאבד את ההתקדמות שלו. מותר להוסיף, לתקן תרגום או לשנות רמה ונושא.
- **האבחון בהגדרות** מציג את כל המודולים שנטענו עם הגרסאות שלהם, ואת 10 השגיאות האחרונות.

## להוסיף מילים או משפטים

1. ב-`content.js`, במערך `CONCEPTS`, מוסיפים שורה:
   `["market2","shop",7,"דוכן","Stall"]` — מזהה ייחודי, נושא, רמה (1–8), פירוש בעברית, פירוש באנגלית.
2. בכל אחד מקבצי `lang-xx.js`, בתוך `words`, מוסיפים שורה אחת:
   `market2|แผงลอย|phaeng loi|פאנג לוי` — מזהה | טקסט בשפה | תעתיק לטיני | הגייה באותיות עבריות.
3. נושא חדש: מוסיפים אותו ל-`WORD_CATS` (או `PHRASE_CATS` למשפטים), אייקון ב-`CAT_ICON`, ומפתח `cat_<נושא>` בכל חמשת קבצי `ui-xx.js`.

## להוסיף שפת לימוד חדשה (למשל צרפתית)

1. ב-`content.js`, באובייקט `LANGS`, מוסיפים שורה:
   `fr: { flag: "🇫🇷", tts: "fr-FR", dir: "ltr", native: "Français", name: { he: "צרפתית", en: "French", ru: "Французский", es: "Francés", ar: "الفرنسية" } }`
2. מעתיקים את `lang-es.js` ל-`lang-fr.js`, משנים את הקוד ל-`'fr'`, ומחליפים אלפבית, תרגומים, צורות נקבה ומטבע.
   את ההערה למסך האותיות אפשר לתת בתוך החבילה: `note: { he: "...", en: "..." }`.
3. מספרים: בסוף הקובץ מגדירים `NUM.fr = { tokens(n, withCurrency) {...} }`, לפי הדוגמה של ספרדית.
4. זהו. `sw.js` מקבל את רשימת הקבצים אוטומטית בבנייה, והמסכים מציגים את השפה החדשה לבד.

## הוצאת גרסה

1. מעלים את מספר הגרסה (`VER` בסקריפט הבנייה). הוא מוטבע אוטומטית ב-`?v=`, בכל הקבצים וב-`sw.js`.
2. בדיקות לפני מסירה: תחביר בכל קובץ; כל מפתח קיים ב-5 שפות הממשק; כל מושג מתורגם בכל חבילה; מנוע המספרים; סיור אוטומטי בכל המסכים ב-5 שפות. בנוסף בודקים עדכון מגרסה קודמת, חבילה חסרה, גרסה לא תואמת, ו-`app.js` חסר.
3. מעלים **את כל הקבצים יחד** לריפו.
4. בטלפון: אם משהו נראה ישן, סוגרים את האפליקציה לגמרי ופותחים מחדש, או לוחצים על פס הרענון.

## עוזר AppNest

המנוע (`appnest-assistant.js`) מועתק כמו שהוא מהגרסה הרשמית. כל ההתאמה ל-LingoNest נמצאת ב-`assistant-map.js`.
המפתח ב-LingoNest מוצפן, ולכן `readAiConfig` מחזיר את המפתח שפוענח בזיכרון בזמן העלייה. אם אין מפתח, העוזר מבקש לחבר אחד.
כשמשפרים את המנוע, מעתיקים את הקובץ החדש כמו שהוא, בלי לגעת במפה.

## תיקוני תוכן מבדיקת האיכות

תיקון שהוחל נשמר במכשיר (`st.fix`) וגובר על קובץ השפה. את הדוח מעתיקים ושולחים, ואז מכניסים את התיקונים לקבצי `lang-xx.js` בגרסה הבאה.
